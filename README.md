# یدک‌جلوبندی (YadakSuspension)

فروشگاه تخصصی قطعات جلوبندی، سیستم تعلیق و فرمان خودروهای ایرانی و مونتاژی (نسخه Storefront با Next.js App Router و داده‌های ماک آماده اتصال به API).

## پیش‌نیازها و اجرای لوکال

```bash
npm install
cp .env.example .env.local
npm run dev
```

برنامه روی `http://localhost:3000` در دسترس است.

## وضعیت دیپلوی روی Vercel

- تنظیمات پیش‌فرض پروژه در حالت `NEXT_PUBLIC_USE_MOCK !== "false"` اجرا می‌شود؛ بنابراین بدون نیاز به بک‌اند، کل سایت روی Vercel با داده‌های ماک و `localStorage` به‌طور کامل کار می‌کند.
- برای اتصال به بک‌اند واقعی در آینده، مقدار `NEXT_PUBLIC_USE_MOCK=false` و `NEXT_PUBLIC_API_URL` را در Environment Variables تنظیم کنید (مستندات قرارداد API در `docs/api-contract.md` موجود است).

## وضعیت توسعه فعلی

- **فاز ۱ تا ۳:** ساختار پایه Next.js 16 (JavaScript)، کیت UI، لایه سرویس/هوک‌های React Query، ماک سرور کامل، استورهای Zustand، هدر ریسپانسیو، جستجوی زنده، دراور سبد خرید، مودال انتخاب خودرو و فوتر.
- **فاز ۴:** صفحه اصلی (`/`) شامل اسلایدر بنر هیرو، فرم جستجوی خودرو و قطعه، خانواده‌های خودرو، کاروسل پک‌های آماده، دسته‌بندی تخصصی، بخش اعتماد و راهنمای فنی نصب.
